# Glossario dei termini utilizzati

Questo glossario raccoglie i principali termini ricorrenti negli articoli del progetto **linuxhub.it**. Le definizioni vogliono uniformare l'uso della terminologia all'interno del sito.

| Termine | Descrizione breve |
|--------|------------------|
| apache | Server web HTTP open source molto diffuso |
| archlinux | Distribuzione GNU/Linux improntata alla semplicità e alla filosofia KISS |
| automazione | Procedure o script che permettono di svolgere compiti ripetitivi in modo automatico |
| bash | Bourne Again SHell, interprete di comandi predefinito in molte distribuzioni |
| caddy | Server web scritto in Go, semplice da configurare |
| capodanno | Articoli o riflessioni legati al periodo di fine anno |
| centos | Distribuzione Linux derivata da Red Hat Enterprise Linux |
| chatgpt | Modello linguistico realizzato da OpenAI |
| chromeos | Sistema operativo di Google basato su kernel Linux |
| debian | Storica distribuzione GNU/Linux nota per la stabilità |
| docker | Piattaforma di containerizzazione di applicazioni |
| fedora | Distribuzione Linux sponsorizzata da Red Hat, orientata all'innovazione |
| flathub | Repository di applicazioni distribuite tramite Flatpak |
| flatpak | Sistema di pacchetti e sandboxing indipendente dalla distribuzione |
| git | Sistema di controllo versione distribuito |
| github | Piattaforma web per l'hosting di progetti git |
| gnome | Popolare ambiente desktop per GNU/Linux |
| go | Linguaggio di programmazione sviluppato da Google |
| java | Linguaggio di programmazione orientato agli oggetti |
| legge | Riferimenti a normative o documenti legali |
| letsencrypt | Autorità di certificazione gratuita che fornisce certificati TLS |
| mongodb | Database NoSQL orientato ai documenti |
| mysql | Database relazionale molto utilizzato |
| natale | Contenuti o iniziative legate alle festività natalizie |
| nextcloud | Suite open source per la gestione di un cloud personale |
| nginx | Server web e reverse proxy leggero e performante |
| nodejs | Runtime JavaScript per l'esecuzione lato server |
| php | Linguaggio di scripting utilizzato principalmente per il web |
| porno | Contenuti non adatti a un pubblico generalista |
| privacy | Tutela e gestione dei dati personali |
| python | Linguaggio di programmazione adatto a molti ambiti |
| regex | Espressioni regolari, utili per l'analisi di stringhe |
| rhel | Red Hat Enterprise Linux, distribuzione commerciale |
| snap | Formato di pacchetti universale sviluppato da Canonical |
| snapcraft | Strumento per creare pacchetti snap |
| ssh | Protocollo di comunicazione sicura da remoto |
| systemd | Sistema di init e gestione dei servizi nelle distribuzioni moderne |
| ubuntu | Distribuzione Linux basata su Debian e mantenuta da Canonical |
| vacanze | Articoli o note legate ai periodi di ferie |
| vanillaos | Distribuzione Linux focalizzata sulla semplicità d'uso |
| vestacp | Pannello di controllo web per server di hosting |
